# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
by reference. Everyone participating in issues, pull requests, discussions, and
any other project space is expected to follow it.

In short: be respectful, assume good faith, critique work rather than people, and
do not harass anyone. Unacceptable behaviour includes personal attacks,
discrimination, sexualized attention, deliberate intimidation, doxxing, and
publishing another person's private information.

## Reporting

Report unacceptable behaviour to the maintainer through GitHub's private
reporting channel (Security → Advisories on this repository) with "conduct" in the
subject. Reports are handled confidentially.

Maintainers may edit or remove comments, close contributions, or block accounts
that violate this policy. Enforcement follows the Contributor Covenant's
community-impact guidelines.
